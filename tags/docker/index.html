spm系统的PaperLens本地部署完整指南

一、这篇文章解决什么问题 PaperLens 是一个稿件元数据核校系统：接入方提交 PDF 或 DOCX，系统在后台完成文件转换、GROBID 结构化解析、参考文献字段解析，然后在独立的浏览器窗口中让编辑核对标题、作者、摘要、关键词、参考文献、声明和统计信息。 本文记录我在 Windows 本地完成部署的全过程： 启动 GROBID、DOCX 转 PDF、paper-meta 等依赖服务； 启动 PaperLens 的前端和 API； 打开接入方测试控制台并创建稿件任务； 理解各个端口和容器的作用； 遇到配置、镜像、端口和旧任务问题时知道如何处理。 本文采用“依赖服务用 Docker、PaperLens 主程序用 npm run dev”的方式。 二、PaperLens 与 paper-meta 的关系 paperlens\ paper-metadata-9-2.zip 解压后的 PaperLens 主项目 paper_meta\ paper-meta 参考文献解析服务/模型项目 PaperLens 是主系统，负责页面、任务队列、文件处理、GROBID 调用和人工核校；paper-meta 是一个独立的参考文献字段解析器，负责从 GROBID 切出的参考文献原文中提取作者、标题、期刊、年份、卷期、页码、DOI 和文献类型等字段。 处理关系如下： PDF/DOCX │ ├─ converter：DOCX → PDF ├─ GROBID：PDF → TEI、正文结构、参考文献原文和坐标 └─ paper-meta：参考文献原文 → 结构化字段 GROBID 提供参考文献在 PDF 中的坐标，paper-meta 不提供坐标；两者不能互相替代。 ...
