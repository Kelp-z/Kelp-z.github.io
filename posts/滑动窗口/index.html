滑动窗口

滑动窗口通常用来处理数组或字符串中的连续区间问题。它通过维护左右边界，在遍历过程中动态扩大或缩小窗口，从而避免重复计算。

无重复字符的最长子串#

题目#

给定一个字符串 s，找出其中不含重复字符的最长子串，并返回该子串的长度。

思路#

使用 left 和 right 表示当前窗口的左右边界，并用 Map 记录每个字符最近一次出现的位置。

  1. right 向右移动，将新字符加入窗口。
  2. 如果新字符已经在当前窗口中出现，将 left 移动到该字符上次出现位置的下一位。
  3. 每次移动后，使用 right - left + 1 更新最长子串长度。

更新左边界时需要使用 Math.max，避免 left 回退到当前窗口之前的位置。

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int n = s.length();
        int ans = 0;
        Map<Character, Integer> map = new HashMap<>();

        for (int left = 0, right = 0; right < n; right++) {
            char c = s.charAt(right);

            if (map.containsKey(c)) {
                // 出现重复字符时，收缩窗口左边界
                left = Math.max(left, map.get(c) + 1);
            }

            ans = Math.max(ans, right - left + 1);
            map.put(c, right);
        }

        return ans;
    }
}

时间复杂度为 O(n)，空间复杂度为 O(k)，其中 k 是字符串中不同字符的数量。

找到字符串中所有字母异位词#

题目#

给定两个字符串 s 和 p，找到 s 中所有 p 的异位词子串，并返回这些子串的起始索引。答案顺序不限。

思路#

异位词具有两个特点：

  1. 子串长度与 p 相同。
  2. 每个字符出现的次数与 p 相同。

因此可以维护一个长度固定为 p.length() 的窗口：右边界每次加入一个字符；当窗口过长时，移除最左边的字符。窗口达到目标长度后，比较窗口与 p 的字符频次数组。

下面的实现假设 s 和 p 只包含小写英文字母。

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> indexes = new ArrayList<>();
        int[] need = new int[26];
        int[] window = new int[26];
        int windowLength = p.length();

        // 统计 p 中每个字符需要出现的次数
        for (char c : p.toCharArray()) {
            need[c - 'a']++;
        }

        for (int right = 0; right < s.length(); right++) {
            // 将右边界字符加入窗口
            window[s.charAt(right) - 'a']++;

            // 窗口过长时，移除最左边的字符
            if (right >= windowLength) {
                window[s.charAt(right - windowLength) - 'a']--;
            }

            // 窗口长度达到 p 的长度，并且字符频次相同
            if (right >= windowLength - 1 && Arrays.equals(need, window)) {
                int left = right - windowLength + 1;
                indexes.add(left);
            }
        }

        return indexes;
    }
}

由于字符集大小固定为 26，比较两个频次数组可以视为常数操作，因此时间复杂度为 O(n)，空间复杂度为 O(1)。

总结#

这两道题分别对应两种常见的滑动窗口形式：

  • 可变长度窗口：窗口不满足条件时移动左边界，例如无重复字符的最长子串。
  • 固定长度窗口：始终维护指定长度的区间，例如查找字母异位词。
