ObjectMapper#

什么是 ObjectMapper#

ObjectMapper 是 Jackson 库中的核心类，用于处理 Java 对象与 JSON 数据之间的相互转换。它是一个功能强大的工具，能够：

  1. 将 Java 对象序列化为 JSON 字符串
  2. 将 JSON 字符串反序列化为 Java 对象
  3. 处理 JSON 数据的解析和生成

ObjectMapper 的作用和用途#

1. REST API 处理#

  • 自动将控制器方法的返回值转换为 JSON 响应
  • 自动将 HTTP 请求体的 JSON 数据转换为 Java 对象

2. 第三方 API 交互#

  • 解析外部 API 返回的 JSON 响应（如我们项目中与企查查 API 的交互）
  • 生成发送给外部 API 的 JSON 请求数据

3. 数据持久化#

  • 将 Java 对象转换为 JSON 格式存储
  • 从 JSON 格式加载数据并转换为 Java 对象

4. 配置文件处理#

  • 解析 JSON 格式的配置文件

ObjectMapperConfig 的作用#

在我们的项目中，ObjectMapperConfig 类的作用是：

  1. 创建并配置 ObjectMapper 实例：通过 @Bean 注解将 ObjectMapper 注册为 Spring 容器中的一个 Bean，使其可以被其他组件注入和使用。

  2. 提供默认配置：虽然配置文件中只是简单地返回了一个新的 ObjectMapper() 实例，但这已经包含了 Jackson 库的默认配置，能够处理大多数常见的 JSON 转换场景。

  3. 便于后续扩展：如果未来需要对 ObjectMapper 进行自定义配置（如设置日期格式、忽略空值等），可以在这个配置类中进行修改。

在我的项目中的应用#

在我们的项目中，ObjectMapper 主要用于：

  1. 解析企查查 API 返回的 JSON 数据：

    • 在 CompanyServiceImpl 中，解析企业基本信息的 JSON 响应
    • 在 PatentServiceImpl 中，解析专利信息的 JSON 响应

  2. 将解析后的数据映射到实体类：

    • 将 JSON 数据转换为 Company 对象
    • 将 JSON 数据转换为 PatentResponse 对象及其关联的实体

  3. 处理 REST API 的响应：

    • 将 Result 对象转换为 JSON 响应返回给客户端

为什么 ObjectMapperConfig 中没有复杂配置#

ObjectMapper 的默认配置已经相当合理，能够处理大多数常见的 JSON 转换场景：

  • 支持基本数据类型的转换
  • 支持复杂对象的嵌套转换
  • 支持集合类型的转换
  • 自动处理空值和默认值

如果未来需要更复杂的配置，可以在 ObjectMapperConfig 中添加，例如：

@Bean
public ObjectMapper objectMapper() {
    ObjectMapper objectMapper = new ObjectMapper();
    // 设置日期格式
    objectMapper.setDateFormat(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"));
    // 忽略空值
    objectMapper.setSerializationInclusion(Include.NON_NULL);
    // 支持枚举类型
    objectMapper.enable(SerializationFeature.INDENT_OUTPUT);
    return objectMapper;
}

总结#

ObjectMapper 用于处理 Java 对象与 JSON 数据之间的转换。在我的项目中，它主要用于与企查查 API 的交互，将 API 返回的 JSON 数据解析为 Java 对象，以便进一步处理和存储。
