public Connection getConnection() throws SQLException {
    // 1. 检查连接池是否已关闭
    if (this.isClosed()) {
        throw new SQLException("HikariDataSource " + this + " has been closed.");
    } 
    // 2. 快速路径：如果快速池存在，直接获取
    else if (this.fastPathPool != null) {
        return this.fastPathPool.getConnection();
    } 
    // 3. 慢路径：双重检查锁定初始化连接池
    else {
        HikariPool result = this.pool;
        if (result == null) {
            synchronized(this) {
                result = this.pool;
                if (result == null) {
                    // 初始化连接池
                    this.pool = result = new HikariPool(this);
                    this.seal();
                }
            }
        }
        return result.getConnection();
    }
}

1. 获取挂起/恢复锁

java
this.suspendResumeLock.acquire();
作用：获取一个锁，用于控制连接池的挂起/恢复操作。

场景	说明
连接池挂起	暂停所有连接获取操作（如维护期间）
连接池恢复	恢复连接获取操作
锁的作用	确保在获取连接期间，连接池不会被挂起
2. 记录开始时间

java
long startTime = ClockSource.currentTime();
作用：记录开始获取连接的时间，用于后续的超时计算和性能统计。

3. 核心循环：获取连接

java
while(true) {
    // 从连接袋中获取连接
    PoolEntry poolEntry = (PoolEntry)this.connectionBag.borrow(timeout, TimeUnit.MILLISECONDS);
    
    if (poolEntry != null) {
        // 连接获取成功，进行有效性检查
        // ...
    }

}
connectionBag.borrow() 是核心方法，从连接池中借出一个连接条目。

4. 连接有效性检查

java
if (!poolEntry.isMarkedEvicted() && 
    (ClockSource.elapsedMillis(poolEntry.lastAccessed, now) <= this.aliveBypassWindowMs || 
     !this.isConnectionDead(poolEntry.connection))) {
    // 连接有效
}
检查逻辑：

检查项	说明
!poolEntry.isMarkedEvicted()	连接未被标记为驱逐
elapsedMillis(...) <= aliveBypassWindowMs	连接最近被访问过（在存活窗口期内）
!isConnectionDead(poolEntry.connection)	连接未死亡（通过 ping 测试）
设计意图：避免使用无效的连接（已关闭、超时、断开等）。

步骤	说明

代理连接的作用：

拦截 close() 方法，实现连接归还而不是真正关闭
记录连接使用信息，用于泄漏检测
