B树 每个节点可以有多个子节点。假设m阶B树（m = 2t，t为最小度数），则： 每个节点最多有m个孩子（2t个） 除根节点外，每个节点至少有t个孩子 每个节点的关键字数量在[t-1, 2t-1]之间 所有叶子节点在同一层 节点内的关键字按升序排列 class BTree{ class BTreeNode{ private int[] keys; private BTreeNode[] children; i < t; i++) { newNode.children[i] = fullChild.children[i + t]; } } // 4. 将fullChild的关键字数更新为t-1（只保留前t-1个） fullChild.n = mid; // 5. 父节点的children数组腾出位置，插入newNode for (int i = parent.n; i > childIndex; i--) { parent.children[i + 1] = parent.children[i]; } parent.children[childIndex + 1] = newNode; // 6. 父节点的keys数组腾出位置，插入fullChild的中间关键字 for (int i = parent.n - 1; i >= childIndex; i--) { parent.keys[i + 1] = parent.keys[i]; } parent.keys[childIndex] = fullChild.keys[mid]; MySQL索引使用规则

MySQL索引使用规则 1. 最左前缀法则 组合索引(a, b, c)的生效顺序为：a → a,b → a,b,c 不能跳过最左侧索引 2. 索引失效场景 失效场景 示例 解决方案 字段做函数 / 运算操作 WHERE SUBSTR(name,1,3)='张' 避免字段运算，改为WHERE name LIKE '张%' 使用OR且非所有字段有索引 WHERE id=1 OR age=20（仅 id 有索引） 要么给 age 加索引，要么拆分查询 使用LIKE %xxx（模糊匹配前缀） WHERE name LIKE '%张三' 改为LIKE '张三%'（前缀匹配），或用全文索引 字段类型隐式转换 字符串字段WHERE phone=13800138000（无引号） 加引号WHERE phone='13800138000' 使用NOT IN/!=/<> WHERE age NOT IN (20,30) 尽量用范围查询替代（如WHERE age <20 OR age>30） NULL 值判断（部分场景） WHERE age IS NULL 若字段频繁查 NULL，可加索引；或用默认值替代 NULL 3. 语法 -- 创建索引（建表时） CREATE TABLE user ( id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(20), age INT, UNIQUE KEY idx_name (name), INDEX idx_age (age), INDEX idx_name_age (name, age) ); -- 建表后创建 CREATE INDEX idx_age ON user(age); -- 普通索引 ALTER TABLE user ADD UNIQUE KEY idx_name (name); -- 唯一索引 ALTER TABLE user ADD PRIMARY KEY (id); -- 主键索引 -- 删除索引 DROP INDEX idx_age ON user; ALTER TABLE user DROP INDEX idx_name; ALTER TABLE user DROP PRIMARY KEY; -- 主键索引删除 4.
